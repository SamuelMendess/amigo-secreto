3 PASSOS PARA ESTAR ONLINE:
════════════════════════════════════════════════════════════════════════════════

PASSO 1: Conectar Vercel ao GitHub (2 minutos)
──────────────────────────────────────────

1. Abra https://vercel.com
2. Faça login com GitHub
3. Clique em "Add New" → "Project"
4. Procure por "amigo-secreto"
5. Clique em "Import"


PASSO 2: Adicionar Variáveis (1 minuto)
─────────────────────────────────────

Na tela de config do Vercel:

Clique em "Environment Variables"

Adicione:
├─ VITE_SUPABASE_URL = [seu url do Supabase]
└─ VITE_SUPABASE_ANON_KEY = [sua chave]

(Copie do Supabase: https://app.supabase.com → Settings → API)


PASSO 3: Deploy (5 minutos)
──────────────────────

1. Clique em "Deploy"
2. Aguarde até aparecer ✅ verde
3. Clique em "Visit"
4. SITE ONLINE! 🎉
