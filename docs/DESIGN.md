# Direção visual

Produto: organizar grupos de amigo secreto no celular, com clareza e sigilo.

- Paleta: pinho #173B35, folha #176449, papel #F3F6F5, branco #FFFFFF, fita #B63F57, texto secundário #52675F.
- Tipografia: Trebuchet MS nos títulos e sistema sans-serif no texto. Sem fontes externas.
- Estrutura: cabeçalho discreto; grupos em lista; telas do grupo com abas para participantes, desejos e resultado. No celular, uma coluna.
- Elemento característico: presente vetorial em CSS na entrada, com fita rosa e etiqueta de papel. O resto da interface é contido.
- Revisão: a pesquisa UI/UX sugeriu uma vitrine rosa; foi adaptada para uma ferramenta de organização. Verde mantém a origem natalina sem limitar o uso a dezembro; rosa é apenas o acento.
- Acessibilidade: alvos de 44 px, labels visíveis, foco, mensagens anunciadas, diálogo com foco contido e suporte a movimento reduzido.
