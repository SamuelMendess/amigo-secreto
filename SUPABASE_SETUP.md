# 🚀 Guia de Configuração - Supabase + Vercel

## Passo 1: Criar Conta no Supabase

1. Acesse [https://supabase.com](https://supabase.com)
2. Clique em "Sign Up" e crie sua conta
3. Crie um novo projeto:
   - **Project Name**: `amigo-secreto`
   - **Database Password**: Crie uma senha forte
   - **Region**: Escolha a mais próxima (ex: Brasil - São Paulo)
4. Aguarde o projeto ser criado (leva alguns minutos)

## Passo 2: Criar Tabela no Supabase

1. Vá para o dashboard do seu projeto
2. Clique em **"SQL Editor"** no menu esquerdo
3. Clique em **"New Query"**
4. Cole este SQL e execute:

```sql
CREATE TABLE food_items (
  id bigint PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  category text NOT NULL CHECK (category IN ('salgados', 'doces', 'bebidas')),
  name text NOT NULL,
  person text NOT NULL,
  created_at timestamp DEFAULT NOW(),
  updated_at timestamp DEFAULT NOW()
);

-- Criar índice para melhor performance
CREATE INDEX food_items_category_idx ON food_items(category);

-- Habilitar Row Level Security (RLS)
ALTER TABLE food_items ENABLE ROW LEVEL SECURITY;

-- Criar política para permitir leitura pública
CREATE POLICY "Allow public read" ON food_items
  FOR SELECT USING (true);

-- Criar política para permitir insert público
CREATE POLICY "Allow public insert" ON food_items
  FOR INSERT WITH CHECK (true);

-- Criar política para permitir delete público
CREATE POLICY "Allow public delete" ON food_items
  FOR DELETE USING (true);
```

## Passo 3: Pegar as Credenciais

1. Vá para **Settings** (ícone de engrenagem)
2. Clique em **API**
3. Copie:
   - **Project URL** → `VITE_SUPABASE_URL`
   - **anon public** → `VITE_SUPABASE_ANON_KEY`

## Passo 4: Configurar Variáveis de Ambiente

### Local (Desenvolvimento)

1. Abra o arquivo `.env` na raiz do projeto
2. Preencha com suas credenciais:

```env
VITE_SUPABASE_URL=https://sua-url.supabase.co
VITE_SUPABASE_ANON_KEY=sua_chave_anonima_aqui
```

3. Salve e reinicie o servidor (`npm run dev`)

### Vercel (Produção)

1. Acesse seu projeto no [Vercel](https://vercel.com)
2. Vá para **Settings** → **Environment Variables**
3. Adicione as mesmas variáveis:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. Deploy novamente

## Passo 5: Testar Localmente

1. Execute `npm run dev`
2. Clique em um participante
3. Vá para o **Mural da Ceia**
4. Adicione um item: ex. "Pudim" por "Samuel"
5. O item deve aparecer em tempo real em todos os navegadores abertos! 🎉

## Passo 6: Deploy no Vercel

```bash
# 1. Faça commit das mudanças
git add .
git commit -m "feat: Add Supabase integration for real-time food items"

# 2. Push para GitHub
git push origin main

# 3. Vercel vai fazer deploy automaticamente
# Acesse seu site em https://seu-projeto.vercel.app
```

## 🔐 Segurança

⚠️ **Importante**: 
- Use apenas a chave `anon public` (não a chave `service_role`)
- Elas estão configuradas em `.env` que é públicas no Vercel (isso é ok para `anon`)
- O Supabase tem autenticação e RLS para proteger dados

## 🆘 Problemas Comuns

### "Erro ao conectar ao banco de dados"
- Verifique se as credenciais estão corretas no `.env`
- Verifique se a tabela `food_items` foi criada
- Verifique se Row Level Security está habilitado

### Itens não aparecem em tempo real
- Recarregue a página
- Verifique se o Supabase está online
- Verifique o console do navegador (F12) para erros

### Deploy no Vercel não funciona
- Certifique-se de que adicionou as variáveis de ambiente no Vercel
- Faça redeploy após adicionar as variáveis
